Random Group Generator

Instructions

How to prepare your CSV file:
1. Participant Columns:
  • Put participant names in separate columns (e.g., one column per bunk, team, or category)
  • First row should contain headers describing each group
  • Each participant goes in a separate row under their respective column
2. Restrictions (Optional):
  • Leave an empty column after your participant columns
  • Add restriction columns with names that shouldn't be in the same group
  • Put names that can't be together in the same row
  • You can have as many restriction columns as needed
Example CSV structure:
Bunk A Bunk B Bunk C Restriction 1 Restriction 2 Restriction 3
Alice Bob Charlie Alice Bob Charlie
David Emma Frank David Emma
Grace Henry Ian Grace
This ensures proportional representation from each bunk while keeping restricted pairs apart.
💡 Tips:
  • The tool will try to create groups with equal representation from each participant column
  • If restrictions can't be avoided, the tool will minimize violations
  • You can generate multiple times to get different random combinations
